# DARK Bridge Club

A private browser bridge table for Darren, Adrian, Ryan and Kim, played over a Messenger call.

- **Plan and decisions:** [docs/plan/README.md](docs/plan/README.md)
- **Specs:** [docs/plan/specs/](docs/plan/specs/)

Status: **M1 (playable, plain) in review.**

- **Put it online:** follow [docs/DEPLOY.md](docs/DEPLOY.md) (one time, about 15 minutes).
- **For developers:** `npm install`, then `npm test` (rules), `npm run e2e` (four browsers playing a night), `npm run dev` (local table at http://localhost:8787/?k=dev).
